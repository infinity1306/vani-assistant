# VANI OS Specification (SPEC.md)

## Vision
VANI (Virtual Autonomous Network Intelligence) is a 100% local, privacy-first, zero-cost intelligence layer that sits directly between the user and their operating system.

## Core Directives
1. Ambient but Available
2. Context over Configuration
3. Fluidity
4. Absolute Privacy

## Current Focus (Frontend)
- **Month 1:** Foundation & The Orb
- **Stack:** React 19, TypeScript, Vite, Tauri v2, TailwindCSS v4, Zustand, Three.js + WebGL Shaders.
- **Key Features:** Ambient Orb shader, Global Summon (Ctrl+Space), WebSocket Real-time Bridge.
